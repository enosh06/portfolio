🌐 Enosh Aji — Portfolio Website

A modern, responsive personal portfolio website built using HTML5 and CSS3, designed to showcase my skills, projects, experience, and contact information as a Full Stack Developer.

📌 Overview

This portfolio is a single-page static website featuring smooth UI interactions, gradient-based modern styling, hover animations, and a clean layout. It highlights my professional profile, technical skills, projects, education, and contact details in a structured and visually appealing way.

✨ Features

🎨 Modern UI with gradients and glassmorphism effects

📱 Fully responsive layout

🚀 Smooth hover animations and transitions

🧑‍💻 Detailed sections for skills, projects, experience, and education

🔗 Direct contact links (Email, GitHub, LinkedIn)

⚡ Lightweight and fast (no frameworks required)

🛠️ Technologies Used

HTML5 – Structure and content

CSS3 – Styling, animations, transitions, gradients

Vanilla CSS – No external libraries or frameworks
